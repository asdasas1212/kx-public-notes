普通表格

列数、列名、空字段、整行重复，以及数字列混入文本。

行情数据

同资产时间排序、重复时间、有限数值、负成交量和 OHLC 价格关系。

Episode 元信息

同 episode 的时间、帧号顺序、帧号重复和不连续。不读取视频或动作张量。

数据如何处理？

CSV 在当前浏览器内解析和检查；此演示不发送文件、不使用第三方统计，也不保存检查内容。报告仅在你点击导出后下载到本机。关闭页面会清除当前检查状态。
